03Recap relámpago — ¿qué era una skill? 📜

.opencode/skills/<nombre>/SKILL.md
┌──────────────────────────────┐
│ ---                          │
│ name: diseno-ui              │ ← cómo se llama
│ description: Aplicá buenos   │
│   principios de diseño…      │ ← CUÁNDO se activa
│ ---                          │
│ # Instrucciones              │ ← LA RECETA
└──────────────────────────────┘
  • Una skill = un archivo de texto con la receta de una tarea (nada más, nada menos)
  • AGENTS.md = reglas de la casa · Skill = receta para una tarea · MCP = el enchufe a servicios
  • Se activa sola si tu pedido matchea la descripción… o la invocás: "usá la skill X"

07Recap — .env en 30 segundos 🔑

❌ Lo que NO va en el código

const API_KEY = "sk-abc123-SECRETO";
// si el código se sube, el secreto se sube

✅ Lo que sí: aparte, en .env

# .env — RAÍZ del proyecto (NO se sube a git)
VITE_PORT=5174
  • Reglas que vimos: prefijo VITE_ obligatorio en Vite, el .env nunca se sube (irá al .gitignore)
  • 📌 Hoy es el caso tranquilo: el puerto no es un secreto. Empezamos por ahí para crear la costumbre de usar .env 🚀
  • ⏳ Los secretos de verdad → backend (próxima clase 😉)

08🛠️ Práctica 2 — tu PRIMER .env (solo el puerto)

  1. Elegí TU número: 4 dígitos, mayor a 1024 (evitá el 5173 "default" de todo el mundo 😄)
  2. En la raíz de mi-tienda, creá el archivo .env — una sola línea:
VITE_PORT=5174

↑ reemplazá el número por el tuyo. Crealo vos a mano… o hacés el paso siguiente y el agente lo crea por vos.

Luego delegás la conexión al agente (clic para copiar):

Creá un archivo .env en la raíz con VITE_PORT=5174
y configurá el vite.config.js para que el servidor
de desarrollo use ese puerto (usá loadEnv para leer
la variable, con 5173 como fallback si no existe).
Explicame en dos líneas qué tocaste.

El diff del vite.config.js es la lección: ahí ves dónde y cómo la variable sale del .env y entra al código 👀

09⚠️ Si el puerto no funciona — checklist de errores comunes

Los clásicos

  • .env no está en la raíz (junto a package.json, no dentro de src/)
  • Espacios alrededor del =: VITE_PORT = 5174 ❌
  • Sin el prefijo VITE_ → la variable no llega al navegador
  • Cambiar el .env sin reiniciar: para el npm run dev y volvé a correrlo (o nueva sesión del agente)
  • Puerto ocupado → elegí otro número

✅ Cómo verificar que anduvo

  1. El agente te muestra el diff → aceptás
  2. npm run dev arranca…
  3. …y dice tu puerto: localhost:5174 → el TUYO 🎯
  4. El navegador carga la tienda en ese puerto

Si algo falla: copiá el error exacto (consola F12 o terminal) y se lo pegás al agente.
